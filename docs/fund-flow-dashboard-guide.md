대상 화면: 관리자 `자산 · 인출 > 자금 환류 대시보드 [1405]` (`fund-flow.html` / `fund-flow.js`)
근거 코드: `AdminFundFlowServiceImpl`, `FundFlowMapper.xml`, `docs/fund-flow-api.md`, `data-generator/docs/analysis/metrics.md`·`SUMMARY.md`
작성 기준: 2026-11-06 코드 기준. 문서 속 숫자는 시드 DB(업무시계 2026-11-18, `asOfDate` 2026-11-17)의 **기준값**이며, 실제 화면 값은 DB 상태에 따라 달라질 수 있다.

> **먼저 알아둘 것**
> 1. 이 화면은 **기술통계(집계·비율·분해) 대시보드**에 **Kaplan–Meier 생존곡선(부트스트랩 신뢰구간)**, **로렌츠 곡선·지니계수**, **계좌별 중앙값**이 더해진 화면이다. 회귀·군집 같은 추정 모형은 화면에 없다 (`data-generator/docs/analysis`의 별도 분석 산출물이고, 화면과 API에는 연결되어 있지 않다. §9 참고).
> 2. 모든 데이터는 **합성(시드 생성) 데이터**다. "RIA 고객은 이렇게 행동한다"는 사실이 아니라, 지표 체계와 집계 로직이 맞게 동작하는지 보여주는 화면이다.
> 3. 화면의 숫자는 **인과 효과가 아니다.** "RIA 덕분에 돌아온 돈"과 "RIA가 없어도 돌아왔을 돈"을 구분하지 못한다.

## 1. 화면 구성과 데이터 흐름

화면이 열리면 JS가 7개 API를 **동시에** 호출하고, 패널마다 따로 로딩·오류(다시 시도)·빈 상태를 가진다. 한 API가 실패해도 나머지는 그려진다.

| API | 채워지는 곳 |
|---|---|
| `/overview` | ① 요약(개설 계좌 수, 복귀 금액, 재투자율) |
| `/relief` | ① 요약(감면액, 감면 1원당), ⑥ 감면 성과 |
| `/leakage` | ① 요약(혜택 상태), ⑤ 혜택 누수 |
| `/monthly` | ② 자금 흐름(Sankey), ③ 월별 콤보, ⑩ 예수금 브리지 |
| `/funnel` | ④ 퍼널 |
| `/allocation` | ⑨ 국내 운용처 |
| `/segments` | ⑪ 연령대 × 투자성향 히트맵 |
| `/retention` | ⑧ 원금 유지 |
| `/concentration` | ⑦ 혜택 집중도 |
| (정적) | ⑫ 지표 정의·데이터 품질 |

공통 규칙 (API 문서 §1):
- **기준일** `asOfDate` = 업무시계 날짜 − 1일. 집계 조건은 `< 업무시계 날짜`. `LocalDate.now()`를 쓰지 않고 `BusinessClockService`를 쓴다. 그래서 시연에서 날짜를 조작하면 이 화면 숫자도 같이 움직인다.
- 금액은 원 단위 `BigDecimal`, 비율은 0~1 소수(화면에서 ×100).
- **기간 선택**(이번 달 / 분기 / 출시 이후)이 있다. 기준일이 속한 달·분기의 첫날부터 기준일까지이고, 흐름형 패널(①~④, ⑧, ⑨의 순매수, ⑩, ⑪)에만 적용된다. 세액 스냅샷 패널(⑤, ⑥, ⑦)은 기준일 값이라 `기간 무관` 배지가 붙고 기간을 따르지 않는다.
- 상단 `PDF로 저장`은 표지 + ①~⑫를 A4 세로로 새 창에서 인쇄한다. 개인 식별 정보는 넣지 않는다.

### 2-1. 금액 정의 (헷갈리기 쉬운 부분)

| 이름 | 정의 | 비고 |
|---|---|---|
| 확정 원화 유입 | `krw_exchange.final_amount` (FINALIZED) | **가정산은 제외** |
| 국내 매수 **체결금액** | `ABS(amount) − fee_amount` | 수수료 제외 원가. 재투자율에 사용 |
| 국내 매도 **체결금액** | `amount + fee_amount + tax_amount` | 수수료·세금 더한 값(매도 총액) |
| 국내 매수 **예수금 순액** | `ABS(amount)` = 체결금액 + 수수료 | 월별 흐름·브리지에 사용 |
| 국내 매도 **예수금 순액** | `amount` = 체결금액 − 수수료 − 거래세 | 월별 흐름·브리지에 사용 |

→ **같은 "국내 매수"라도 상단 재투자율(체결금액)과 월별 그래프(예수금 순액)는 수수료만큼 값이 다르다.** 화면 ②·⑫에 이 차이를 직접 안내하고 있다(백엔드 요청 #74). 예수금 항등식을 맞추려면 순액, 재투자율을 부풀리지 않으려면 체결금액을 써야 하기 때문이다.

## 4. 패널별 상세: 계산 · 해석

### ① 요약 6칸

| 칸 | 계산 | 기준값 | 해석 |
|---|---|---|---|
| 누적 개설 계좌 | `opened_at` 있는 계좌 | 75,046 | 누적 개설자(해지 포함). 기간과 무관 |
| 복귀 금액(확정 원화) | Σ `final_amount` (FINALIZED) | 약 6,026.6억 | RIA에서 **원화로 확정**된 총액. 가정산·미확정 제외 |
| 국내 재투자율 | Σ매수 체결금액 ÷ Σ확정 유입 | 70.7% (4,260.2억 ÷ 6,026.6억) | 해외 매도 후 확정된 원화 중 국내 매수에 쓴 비율 |
| 예상 감면액(조세지출) `잠정` | Σ(일반 과세 − 최종세액) | 팀 산출값 | 정부가 포기한 세수의 **예상치** |
| 감면 1원당 국내 운용액 `잠정` | Σ순투자 ÷ Σ감면액 | 전체 21.0 / 감면>0 계좌만 15.1 | 세금 1원을 깎아줄 때 국내에 순투자된 금액 |
| 혜택 상태 | 정상/부분 축소/취소 비중 (**매도한 계좌** 기준) | 정상 75.2% · 부분 축소 18.0% · 취소 6.9% | §⑤ 참고 |

핵심 포인트
- **재투자율은 "계좌별 비율의 평균"이 아니라 "합계 비율"**이다. 큰 계좌가 더 큰 비중을 갖는다 → "금액 기준으로 전체 자금의 몇 %가 국내로 갔나"에 대한 답.
- 재투자율은 100%를 넘을 수 있다(국내 매도 현금이 다시 국내 매수로 재순환되기 때문).
- 순투자율 = (Σ매수 − Σ매도) ÷ Σ확정 유입 = 63.3%. **재투자율(70.7%)과의 차이 7.4%p는 국내에서 다시 팔아 현금화한 몫**이다. 정책 목적(국내 시장 복귀)에 더 가까운 지표는 순투자율이다.
- `잠정` 배지가 붙은 두 칸은 정의 `draft-1` 기준 예상값이다.

### ② 자금 흐름 경로 (Sankey)

```
해외 매도 ─▶ 확정 원화 ─┬▶ 국내 매수
                        ├▶ 예수금 잔류
            국내 매도 회수 ┴▶ 인출
```
- 월별 합계(`/monthly`)를 합쳐서 그린다. 예수금 잔류 = 확정 원화 + 국내 매도 회수 − 국내 매수 − 인출.
- **"차이" 노드**: 해외 매도액과 확정 원화는 같지 않다. 환율·수수료, 아직 확정되지 않은 가환전 때문이다. 이 잔차를 회색으로 따로 보여서 "숨은 불일치"가 없게 한다.
- ⚠ 연결선이 어느 출처에서 어느 목적지로 갔는지는 **표시용 배치**(인출 → 국내 매수 → 잔류 순서로 채움)다. **노드 금액만 실제 합계**이고, 리본의 굵기를 "이 돈이 저기로 갔다"는 개별 추적으로 읽으면 안 된다.
- 비율은 해외 매도 대비. 진행 중인 달(11월)은 기준일까지만 포함.

### ③ 월별 유입 · 국내 매수와 재투자율

- 막대 2개(확정 원화 유입, 국내 매수) + 선(월 재투자율 = 매수 ÷ 유입).
- 세로 점선 5/31, 7/31 = **공제율 구간 경계**(1~5월 100% / 6~7월 80% / 8~12월 50%). 구간이 바뀌는 시점에 유입이 몰리거나 꺼지는지 눈으로 확인하는 장치.
- 빗금 막대 = 진행 중인 달(부분 집계).
- 해석
  - 월 재투자율이 100%를 넘으면 그 달 유입보다 더 많이 샀다는 뜻(과거 예수금·국내 매도 재순환).
  - 유입은 많은데 선이 낮으면 돈이 예수금에 머무는 중.
  - 마감 직전 매도 몰림(구간 경계 직전 급증)은 가설일 뿐, 이 화면에서는 인과로 단정하지 않는다.
  - 월별 국내 매수는 **수수료 포함 순액**이라 상단 70.7%와 월별 비율의 평균은 일치하지 않는다.

| 4 | 부분 축소 | 0 < 조정비율 < 1 | 9,441 | 12.6% |
| 5 | 타 계좌 순매수로 소멸 | 조정비율 = 0 | 1,812 | 2.4% |

**조정비율**은 프로젝트 세액 5단계의 [3] `1 − (RIA 외 순매수 가중합 ÷ RIA 내 매도 가중합)`이다 (0~1 clamp). 값이 작을수록 다른 계좌에서 해외주식을 다시 사서 혜택이 줄었다는 뜻.

해석 시 주의점
1. **조정비율 0을 "누수"로 한 덩어리로 보면 안 된다.** 0인 계좌 26,119개 중 22,518개는 애초에 매도가 없어서 조정할 대상이 없고, 1,789개는 해지로 취소됐다. **진짜 "타 계좌 순매수로 소멸"은 1,812개(2.4%)뿐**이다. 그래서 5개로 쪼갰다.
2. 상단 ① "혜택 상태"는 **매도 없음을 분모에서 뺀다**(52,528 = 75,046 − 22,518). 그리고 3그룹으로 묶는다: 정상(영향 없음) / 부분 축소 / 취소(혜택 취소 + 순매수 소멸). 그래서 같은 데이터인데 ⑤의 52.6%(전체 기준)와 ①의 75.2%(매도 계좌 기준)가 다르다. 분모가 다를 뿐이다.
3. 계좌 관리 화면의 "일부 감액"(외부 순매수가 있는 모든 계좌)과는 다른 정의다.
4. 표의 "타 계좌 순매수 있음" 열은 `weighted_external_amount > 0` 계좌 수. 순매수가 있어도 조정비율이 1일 수 있어(예: 매도액이 훨씬 커서 영향이 미미) "혜택 축소"와 구분해서 읽는다.
5. 하단 검증 문구: ①의 3그룹 값을 ⑤ 행에서 다시 계산해 **화면 두 곳의 숫자가 일치하는지 자체 검산**한다 (`✓` / `✗`).
6. `tax_snapshot`은 표시용 캐시(2026-11-17 02:00 배치)이며 **확정 세액이 아니다.** 확정 근거는 `tax_calculation`.

### ⑥ 감면 성과 `잠정`

```
일반 과세 세액 = 세율(22%) × max(0, 비가중 총양도소득 − 기본공제 250만)
감면액         = 일반 과세 세액 − 최종세액(final_tax)
감면 비율      = 감면액 ÷ 일반 과세 세액
감면 1원당 운용 = Σ국내 순투자(매수 체결 − 매도 체결) ÷ Σ감면액
```
- 워터폴: 일반 과세 세액 → (−감면액) → 최종 세액. 세 값이 안 맞으면 "차이" 막대가 생긴다.
- `scope=ALL`(전체 개설자, 기본)과 `POSITIVE`(감면 > 0 계좌만)가 있다. 감면을 받는 계좌는 약 27%(20,333개)뿐이라 **분모가 바뀌면 값이 크게 변한다** (21.0원 vs 15.1원).
  - "정책 비용 대비 전체 환류" → 전체 계좌
  - "감면 받은 계좌의 환류" → 감면 > 0 계좌
  - 어느 쪽을 기본으로 할지는 아직 팀 합의 대기.
- 감면액은 구조상 음수가 될 수 없다(`final_deduction ≥ 0`).
- 양도소득이 기본공제 250만 이하면 공제액이 있어도 감면세액은 0이다(소득 기준 공제 ≠ 세액 기준 감면).
- ⚠ 잠정인 이유: `original_gain_amount`가 **RIA 매도분만인지 연간 총 양도소득인지** 김민석 확인 대기. 화면은 총 양도소득으로 가정한다.
- "감면 1원당 21.0원"은 **상관/배분 지표이지 정책 효과가 아니다.** "세금 1원 깎아주면 21원이 국내로 들어온다"로 읽으면 틀린다(원래 돌아왔을 돈이 섞여 있음).

### ⑦ 혜택 집중도 (잠정)

- 감면액(일반 과세 − 최종세액)이 0보다 큰 계좌만 줄 세운 로렌츠 곡선, 지니계수, 상위 10% 점유율.
- 읽는 법: 곡선이 대각선(완전 균등)에서 멀수록, 지니계수가 1에 가까울수록 소수 계좌에 감면이 몰린다.
- 한계: 감면액은 양도소득이 클수록 커지는 구조라 집중이 곧 불공평은 아니다(규모 효과). 자산 규모 구간별 형평성 분석은 구간 정의가 없어 아직 못 한다. 감면액 정의가 잠정이라 값도 잠정이다. 세액 스냅샷 기준이므로 기간과 무관하다.

### ⑧ 원금 유지 (Kaplan–Meier)

- 단위는 환전이 확정된 한 건. 시작은 확정 시각, 사건은 그 건의 1년 미경과 원금 인출, 사건이 없으면 기준일에서 **중도절단**한다. 아직 사건이 안 일어난 건도 버리지 않고 "그때까지는 유지됨"이라는 정보로 쓰는 것이 생존분석의 핵심이다.
- 곡선 = 확정 후 N일까지 원금이 유지된 확률. 띠 = 95% 구간. 같은 계좌의 건은 사건 시점을 공유하므로 **계좌를 단위로 200번 다시 뽑는 부트스트랩**으로 구했다(시드 고정, 재현 가능).
- 읽는 법: 곡선이 내려갈수록 중간 인출이 늘어난다. 띠가 넓어지는 오른쪽 끝은 아직 오래 관찰된 건이 적다는 뜻이라(아래 위험집합 열) 해석을 조심한다. 금액 가중 값이 건수 값보다 높으면 큰 금액은 상대적으로 덜 인출됐다.
- 회색 구간 = 아직 관찰되지 않은 영역. 최대 관찰이 1년에 못 미쳐 **1년 유지율은 정의하지 않는다.**
- 세로축은 변화가 보이도록 아래쪽을 잘랐고 시작값을 각주에 적는다.
- ⚠ 합성 데이터에서는 1년 미경과 원금 인출이 해지 강제 인출뿐이라, 곡선의 모양은 고객 행동이 아니라 생성 규칙의 결과일 수 있다.

### ⑨ 국내 운용처

- 막대: 업종별 매입금액 상위 5 + ETF·펀드(별도) + 기타(나머지 업종). 비중 = 금액 ÷ 전체 합.
- **HHI(허핀달–허쉬만 지수)** = Σ(점유율²), 0(분산) ~ 1(쏠림).
  - 구성 쏠림 HHI: 업종(+ETF·펀드) 단위
  - 종목 쏠림 HHI: 종목 단위
  - 막대는 상위 5로 묶어 보여주지만 **HHI는 묶기 전 전체 buckets로 계산**한 응답 값 그대로다 (화면에서 다시 계산한 값 아님).
  - 일반 감각: 업종 10개가 균등하면 0.1, 한 업종 독점이면 1.0. 분석 결과 기준 업종 HHI ≈ 0.174, 종목 HHI ≈ 0.055 *(평가액 기준 분석값. 화면은 매입금액 기준이라 숫자가 다르다)*.
- 순매수 Top 10 = 종목별 (매수 체결금액 − 매도 체결금액) 상위. 많이 순매수된 종목 = "자금이 모이는 곳".
- ⚠ **매입금액 기준**(`qty × 평균 매입가`)이다. 현재가 평가액이 아니다(종가는 증권사 DB에 있고, 타 시스템은 API로만 접근하는 원칙 때문). 오른 종목의 비중이 과소평가될 수 있다. 예수금은 포함하지 않는다.
- 업종은 주식에만 있어서 펀드·ETF는 한 덩어리로 묶인다.

### ⑩ 예수금 브리지 (워터폴)

월을 고르면 `월초 예수금 → +확정 원화 유입 → −국내 매수 → +국내 매도 → −인출 → 월말 예수금`을 막대로 보여준다.
- **항등식 검산**: 계산한 월말과 실제 월말 예수금이 1원 이상 다르면 회색 "차이" 막대가 생기고 경고 문구가 뜬다. 즉 이 패널은 **데이터 정합성 점검용**이기도 하다. 차이가 없으면 "일치해요"가 뜬다.
- 진행 중인 달은 월말 값이 없어 "진행 중"으로 표시, 월초는 전월 월말을 승계한다.

### ⑪ 연령대 × 투자성향 히트맵

- 연령대 5구간(20대 이하/30대/40대/50대/60대 이상, **기준일 만 나이**) × 투자성향 + 소계 행·열 + 전체.
- 지표 토글: 재투자율 / 순투자율. 색은 이 표 안의 최솟값~최댓값 기준 **상대 색칠**이다 (다른 지표와 색 절대값 비교 금지).
- **칸 값 = 칸별 합계 비율**(Σ매수 ÷ Σ유입). 계좌별 비율의 평균·중앙값이 아니다.
- **소규모 셀 마스킹(k-익명성, k=5)**: 계좌 5개 미만인 칸은 합계·비율을 `null`로 내려보내 `-`로 표시한다(개인 식별 방지). 칸 크기(`accounts`)만 내려가고 비공개 칸 수는 범례에 표시된다.
- 해석: 높은 칸 = 해당 세그먼트가 유입 대비 국내 매수를 많이 하는 집단. 단, 칸마다 계좌 수가 크게 다를 수 있어 소수 계좌 칸의 극단값에 과해석 금지. 계좌별 비율의 분포(중앙값)는 이번 범위에서 제외됐다(#73).

### ⑫ 지표 정의 · 데이터 품질

각 지표의 **분자 / 분모 / 대상 / 기준 시각** 표와 "한계" 문구. 이 표가 화면 숫자 해석의 기준이다. 한계로 명시된 것:
- 혜택 상태 3분류 묶는 기준과 분모
- 국내 매수 기준 차이(체결금액 vs 예수금 순액)
- 잠정 지표(감면) 성격
- 화면에 없는 지표: 금액 기준 퍼널 전환(API 없음), 자산 규모 구간별 형평성(구간 정의 미확정)
- 인과 효과 아님 / 5명 미만 칸 비공개 / PDF 저장은 감사 로그 미기록(#75)

## 5. 해석 체크리스트

숫자를 볼 때 이 순서로 확인하면 오독을 줄일 수 있다.

1. **분모가 무엇인가?** 개설자(75,046) vs 현재 개설(72,013) vs 매도한 계좌(52,528) vs 가입자(95,050). 같은 "계좌 비율"이어도 분모가 다르다.
2. **금액 기준이 무엇인가?** 체결금액(수수료 제외) vs 예수금 순액(수수료 포함). 상단 vs 월별 패널.
3. **합계 비율인가 평균 비율인가?** 이 화면은 거의 전부 합계 비율.
4. **확정인가 예상인가?** 확정 원화 vs 가정산, 세액 스냅샷(예상). `잠정` 배지.
5. **기준일은 언제인가?** 각 카드의 "집계 기준일". 진행 중인 달은 부분 집계(빗금).
6. **평가액인가 매입금액인가?** 운용처는 매입금액.
7. **인과인가 상관인가?** 전부 상관·기술 통계. "RIA가 X%를 늘렸다"로 쓰면 안 된다.

## 9. 화면에 없는 분석 (참고)

`data-generator/docs/analysis`의 아래 분석은 **화면과 API에 연결되어 있지 않다.** 위 ①~⑪의 실시간 숫자와 섞어 말하지 않도록 구분한다. 표의 원금 유지·혜택 집중도는 ⑧·⑦에서 실시간으로 계산한다.

| 분석 | 방법 | 비고 |
|---|---|---|
| 원금 유지(S4) | Kaplan–Meier + 계좌 단위 부트스트랩 | **화면 ⑧에 구현됨.** 서비스 시작이 2026-03-23이라 1년 유지율은 정의 불가, 236일 관찰. 210일 시점 95.5% |
| M1 마감 직전 매도 몰림 | 매도일 선택 조건부 로짓 | 3.07배(정답 3.00) |
| M2 해지 요인 | 로그 링크 이항(수정 포아송) | |
| M3 재투자 비율 | fractional logit | 반응비 1.2701 |
| M4 첫 매수까지 시간 | 누적발생(cmprsk) | 경쟁 사건 0건 |
| M5 종목 선택 | 표본추출 조건부 로짓 | |
| M6 고객 세분화 | GMM + BIC + 부트스트랩 | K=6 |
| 혜택 집중도 | 로렌츠/지니 | **화면 ⑦에 구현됨.** 지니 0.53, 상위 10% 점유 35.8% |
| 형평성(Theil 분해) | 자산 규모 구간별 집중 분해 | 화면에 없음. 구간 정의 필요 |

이 분석들은 "정답을 아는 합성 데이터로 추정 방법이 맞는지 검증"한 결과이며, 실제 고객 행동의 발견이 아니다.
